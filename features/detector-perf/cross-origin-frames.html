detectorPerf — cross-origin frames

Each frame below is a separate document with its own C-S-S injection and its own detectorPerf accumulators. On debug builds every frame renders its own live stats overlay, and the top page renders one for the top frame — per-frame measurement is visible side by side across real origin boundaries.

The third-party frames use the shared test domains (good.third-party.site is not on the blocklist, broken.third-party.site is on it with action "ignore"), which resolve to this same site in production. They only load once the page is served from privacy-test-pages.site — when running locally, only the same-origin frame works.
