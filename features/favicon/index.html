SVG and PDF favicons

Favicons that browsers render themselves. The ones with a filter crash apps that draw them with the system SVG renderer (NSImage on macOS), so open them only in a browser that draws favicons in a separate process.

  • SVG with a filter on the root and on a child — shows Dax, no crash
  • The same SVG, encoded as UTF-16 — shows Dax, no crash
  • The same SVG, after a long comment — shows Dax, no crash
  • SVG declared at 16x16 — shows a sharp Dax
  • SVG with only a view box — shows Dax
  • SVG colored only through CSS — shows an orange circle
  • PDF favicon — shows an orange circle, no crash
  • HTML served as a favicon — shows the default grey icon, no crash and no hang
