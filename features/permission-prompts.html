How this maps to the per-site permission flow
  • Allow once vs. always: grant, press Stop, then Request again. "Allow once" should re-prompt; "Always allow" should resolve with no dialog. Watch the State row update live.
  • Never allow: once set, Request should reject immediately with no dialog and Last result shows NotAllowedError.
  • Active-in-use animation: while a permission is live the card border turns green and the dot pulses — camera shows a preview, microphone shows a live level meter, location keeps updating coords. This is the state the menu indicator/animation should mirror.
  • Denied system permission recovery: if the site permission is allowed but the OS-level permission is off, getUserMedia rejects with NotAllowedError (see Last result / log). That's the case where the app should surface a "open system settings" link.
