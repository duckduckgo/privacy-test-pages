Site Permissions (SVG documents)

Requests location, camera and microphone from SVG documents, to check that a browser's permission handling also covers documents that aren't HTML. Each document shows its content type, root element and origin, then the result of each request.

Top-level documents

  • SVG document: served as image/svg+xml with an <svg> root. Requests should behave as they do on an HTML page from the same site.
  • Arbitrary XML document: also served as image/svg+xml, but its root is <document>, so it isn't an SVG document. Use it to check that SVG-specific handling doesn't apply to other XML.
  • HTML baseline (Geolocation) to compare with.

Same-origin SVG iframe

Embedded with allow="geolocation; camera; microphone". Requests should behave as they do in the top-level SVG document.

Cross-origin SVG iframe

Origin: -. Embedded with the same allow attribute. Compare the results with the HTML iframes on the iframe identity page.
