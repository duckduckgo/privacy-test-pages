Bottom pinned chat input

On a phone, tap the message field to open the keyboard. Type, add new lines, send messages, scroll the conversation, rotate the device, then dismiss and reopen the keyboard. Check whether the input and Send button remain visible and usable, and whether the input returns to the bottom after the keyboard closes.

The composer uses position: fixed; bottom: 0 with safe-area padding. No JavaScript adjusts its position for the keyboard. Messages stay on this page and are cleared on reload.
